# SyncStrive - A Modern Todo App

A beautiful and efficient todo application built with Flutter, featuring a clean UI and intuitive task management. This app was created as a task for WebReInvent.

## About

SyncStrive is a productivity tool designed to help users organize their daily tasks with a modern interface and smooth user experience. It was developed as part of a technical assessment task for WebReInvent.

## Features

- **Beautiful UI**: Modern, sleek design with animations and consistent theming
- **Task Management**: Create, edit, and delete tasks with ease
- **Categories**: Organize tasks into custom lists
- **Subtasks**: Break down complex tasks into manageable subtasks
- **Due Dates**: Set and track deadlines for your tasks
- **Tags**: Add custom tags to categorize and filter tasks
- **Persistent Storage**: Tasks are saved between app sessions

## Getting Started

### Prerequisites

- Flutter 2.10.0 or higher
- Dart 2.16.0 or higher

### Installation

1. Clone the repository

   ```
   git clone https://github.com/yourusername/syncstrive.git
   ```

2. Navigate to the project directory

   ```
   cd syncstrive
   ```

3. Install dependencies

   ```
   flutter pub get
   ```

4. Run the app
   ```
   flutter run
   ```

## Architecture

The app follows a clean architecture approach:

- **Domain**: Contains the business logic and entities
- **Data**: Manages data sources and repositories
- **Presentation**: Handles UI components and state management with Provider

## Dependencies

- provider: For state management
- shared_preferences: For local data persistence
- intl: For date formatting
